Cara memakai admin

  1. Edit konten di menu kiri, lalu klik Simpan perubahan.
  2. Foto bisa diunggah dari perangkat (atau tetap pakai URL). File akan dikompres otomatis.
  3. Perubahan langsung terlihat di situs (browser yang sama) via penyimpanan lokal.
  4. Untuk deploy permanen: klik Export data.js, ganti file js/data.js di hosting.
